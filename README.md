# My First Website

A simple starter website for the Goodwall **#ShareMyProject** challenge.

## Files
- `index.html` — the complete responsive website.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` (or `master`) and folder `/ (root)`, then save.
5. Wait a few minutes for the site to publish.

## Personalize it
Edit the text in `index.html` to describe your real project and goals before submitting.
